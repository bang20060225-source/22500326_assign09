홈 도서 관리

나만의 독서 기록장

읽고 싶은 책, 읽은 책을 등록하고 관리하는 도서 관리 서비스입니다.
데이터는 브라우저 메모리가 아닌 MockAPI(REST API) 서버에 저장되어 새로고침해도 유지됩니다.

도서 관리 시작하기 →

GET

시작 시 서버에서 도서 목록을 불러와 표로 보여줍니다.

POST

입력 검증을 통과한 새 도서를 서버에 추가합니다.

PATCH

기존 데이터를 불러와 폼에서 수정하고 서버에 반영합니다.

DELETE

삭제 확인(confirm) 후 서버에서 도서를 삭제합니다.

데이터 흐름

  1. HTML Form
  2. JS Event / Validation
  3. fetch()
  4. MockAPI (REST API)
  5. JSON Response
  6. DOM 화면 갱신
